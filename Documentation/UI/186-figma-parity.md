## 디자인과 제품 데이터의 차이

- 앱 이름은 현재 제품의 `현장가드`를 유지한다.
- 팀 계정은 관리자 발급이다. Figma 회원가입은 현재 앱/API 기능에 없는 별도 제품 흐름이다.
- 탈퇴는 팀과 팀원 계정을 비활성화하며 즉시 기록 삭제가 아니다. 검증된 서버 계약에 맞는 안내를 유지한다.
- 알림 API에 본문이 없고 기록 목록에 사진 URL이 없다. 실제 데이터 없이 본문·사진을 만들지 않는다.
- 체크리스트 수와 측정 일정의 완료 상태는 서로 다른 데이터다. 일정 완료 점을 임의로 연결하지 않는다.
- 취소 확인 및 인트로는 기존 앱 흐름에 없는 별도 화면이다. 이번 변경은 구현되어 있는 화면의 시각적 보정이다.

## 검증

- XcodeBuildMCP unsigned Debug build / install / launch: 성공. 최종 변경 후 재실행했다.
- XCTest: 26개 통과(기존 19 + 날짜5 + 폰트1 + 렌더링1), 실패0.
- `plutil -lint Configuration/Info.plist`, `git diff --check`: 성공.
- UIHostingController로 실제 SwiftUI 화면 8종을 402×874, 320×568에 렌더링한 16개 XCTest 첨부를 보존했다. API 요청/사용자 사진 없이 기본 상태 또는 명시적 fixture를 사용했다.
- 캡처: `Documentation/PRScreenshots/186`. 로그인 시뮬레이터 캡처도 포함한다.
- 렌더링 테스트의 이미지 크기 검사는 회귀 이미지 비교나 전체 E2E 증명이 아니다. 로그인·작업·저장·탈퇴 캡처는 눈으로 확인했다. 저장 fixture는 시트 내용 렌더링이며 실제 업로드 완료 증거가 아니다.
- 초기 샌드박스 실행은 CoreSimulator 연결 거부로 실패했으며 승인된 실행에서 테스트를 재실행했다.
- 네이티브 UI 자동화의 SimulatorKit.framework 누락으로 로그인 후 전체 실제 계정 흐름 자동 탐색은 불가했다. 실기기 촬영·업로드·서버 재조회는 이번 작업에서 실행하지 않았다.

## 폰트

Noto Sans KR은 Google Fonts의 공식 `ofl/notosanskr/NotoSansKR[wght].ttf`에서 fontTools 4.60.2 instancer로 wght 400/500/700 정적 인스턴스를 생성했다. PostScript 이름과 앱 등록을 테스트했다. 원본 SIL OFL 1.1 라이선스는 `Resources/Fonts/NotoSansKR-OFL.txt`에 포함했다.
