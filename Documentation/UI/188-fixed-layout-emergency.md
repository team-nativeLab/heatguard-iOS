# #188 고정 화면과 긴급호출 확인 단계

## 고정 화면

사용자 지시에 따라 로그인, 홈, 작업/휴식 사진, 온도계 입력, 현장 사진, 사진 누락 안내, 기록 상세, 프로필/비밀번호, 탈퇴, 공통 상태 팝업의 `ScrollView`를 제거했다.

`HGFixedContent`가 자연 높이를 측정하고 사용 가능한 높이를 넘을 때 콘텐츠를 축소한다. 화면 폭은 유지하며 확대하지 않는다. 하단 작업 버튼은 `safeAreaInset`에 유지하여 크기와 위치를 보존한다. 기준 화면에서 콘텐츠가 들어오면 원래 크기를 사용한다.

기록/알림/문의의 가변 데이터 목록은 기존 `List`다. 메모 입력의 `TextEditor` 내부 스크롤은 다중 줄 텍스트 입력 동작이다. 화면 전체를 감싸는 `ScrollView`는 없다.

Figma 기준 화면: 작업 `1:1538`, 휴식 `1:1558`, 로그인 `1:1729`. 이전 #186 문서의 프레임 ID 오기를 감사 표 기준으로 정정했다.

402×874의 정상 날씨 작업 화면은 313pt 사진 영역과 원래 간격을 유지한다. 날씨 입력 추가 상태와 320×568에서는 콘텐츠가 축소된다. 모든 기기에서 동일한 절대 글꼴/사진 크기를 보장하는 방식은 아니다.

## 긴급호출

이전 홈 버튼은 현재 호출을 조회하고 ACTIVE/ACKNOWLEDGED가 있으면 호출 안내를 생략해 '긴급 호출 중' 화면으로 갔다. 그 경로는 신규 호출 POST는 하지 않았지만 사용자에게 바로 호출된 것처럼 보였다.

수정 후:

1. 홈 버튼 → 항상 '긴급 호출하기' 안내 창. 서버 요청 없음.
2. 안내 창의 '호출하기' → 현재 호출 조회.
3. 진행 중인 호출이 있으면 해당 상태를 표시하고, 없으면 신규 호출을 생성.
4. 조회/생성 실패는 안내 창에 오류를 표시. 처리 중 반복 호출은 차단.

본사 전화 버튼의 전화 앱 연결은 별도 동작이다. 실제 관리자에게 알림을 보내는 호출 API는 검증 과정에서 실행하지 않았다.
