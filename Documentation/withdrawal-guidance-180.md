# 회원탈퇴 안내 및 인증 오류 제목 수정

## 서버 계약과 수정 범위
- 팀 로그인은 잘못된 인증 정보에 401 INVALID_CREDENTIALS, 비활성화 계정에 403 ACCOUNT_DISABLED를 반환합니다.
- DELETE /api/v1/team/me는 현재 비밀번호를 검증하고 팀과 해당 팀원 전체를 비활성화하며 팀원들의 세션을 삭제합니다.
- 계정과 기록을 즉시 물리적으로 삭제하거나 재가입 시 기록 연결을 보장하는 처리가 아니므로 해당 단정 문구를 제거했습니다.
- 서버 코드는 변경하지 않았습니다. iOS 오류 제목과 안내 문구만 변경했습니다.

## 변경 구분
1. 인증 오류 코드별 제목과 일반 401/403 제목 구분, 오류 메시지와 진단 코드 보존, 회귀 XCTest 7개 추가.
2. 안내 화면과 최종 확인창의 즉시 삭제 문구 수정, 근거 없는 법정 보관 기간 및 재가입 기록 안내 제거.
3. 안내 화면, 동의 체크박스, 최종 확인창에 팀 전체 계정 비활성화 및 세션 종료 범위 표시.

## 검증
- sh scripts/test-notifications.sh: 인증 오류 7개와 알림 이동 12개, 총 19개 통과. 실제 Core 소스를 사용하는 macOS SwiftPM XCTest이며 iOS UI 테스트 타깃은 아닙니다.
- iPhone 17e 대상 서명된 Debug 시뮬레이터 빌드 성공.
- iPhone 17e: 추가 안내 및 긴 동의 문구는 스크롤하여 전체 확인 가능. 비밀번호 미입력 시 제출 비활성화 유지. 임시 문자열 입력 후 최종 확인창까지 열어 문구와 버튼 배치 확인.
- iPhone 18 Pro Max: 안내와 동의 문구 및 하단 제출 버튼 배치 확인.
- 실제 비활성화 계정 재로그인: 403 ACCOUNT_DISABLED 제목이 비활성화 안내로 표시됨.
- 실제 잘못된 비밀번호 로그인: 401 INVALID_CREDENTIALS 제목이 로그인 정보 확인으로 표시됨.
- 기존 테스트 계정 정상 로그인 복원.
- 실제 탈퇴 요청은 이번 수정 검증에서 다시 수행하지 않았습니다.

## 남은 검증 범위
- 실제 기기, 소프트웨어 키보드 표시 및 확대 글꼴 상태는 이번 범위에서 재검증하지 않았습니다.
- Device Hub 좌표 조작이 noWindowsAvailable로 실패하여 변경된 확인창의 취소 버튼 런타임 재검증은 완료하지 못했습니다. 취소 로직은 변경하지 않았으며 재실행으로 임시 화면 상태를 정리했습니다.
