# 현장 앱 화면 정합성 점검 (#153)

기준: Figma 현장 앱 화면과 iPhone 18 Pro 시뮬레이터의 테스트 계정 화면. 실제 사용자 사진이나 시스템 상태 막대는 비교 대상에서 제외했다.

| 화면 | 확인 결과 | 반영 사항 |
| --- | --- | --- |
| 홈, 메뉴 | 핵심 배치와 이동 경로 확인 | 기존 구현 유지 |
| 온도계, 현장 사진, 휴식 사진, 사진 재선택 | 기록 화면의 알림 버튼이 비어 있었음 | 공통 헤더의 알림 버튼과 읽지 않은 수를 연결 |
| 기록 내역 | 영문 날짜, 단일 목록, 사진 없는 데이터의 표시 차이 | 한국어 날짜와 시간, 날짜별 묶음, 빈 화면용 카메라 자산 적용 |
| 기록 상세 | 영문 촬영 시간과 정보 행의 배치 차이 | 한국어 시간, 위치와 유형 행, 사진 자리 표시 조정 |
| 알림 | 빈 화면과 목록의 배치 차이 | 빈 화면 문구와 날짜별 목록 적용 |
| 내 정보 수정 | 회사명과 이메일 편집 상태 차이 | 회사명 표시, 이메일 읽기 전용, 이름과 전화번호 저장 유지 |
| 문의 | 본문 입력 안내와 날짜 표현 차이 | 입력 안내와 한국어 날짜 적용 |
| 비밀번호 변경, 탈퇴 안내, 긴급 호출 | 화면과 이동 경로 확인 | 이번 변경 범위에서 추가 수정 없음 |

## 남은 데이터 제약

- 기록 목록 응답에는 사진 URL이 없어 실제 사진 썸네일을 표시할 수 없다. 목록에는 유형 아이콘을 표시한다.
- 기록 목록 응답은 `nextCursor`와 `hasMore`를 주지만 전체 건수를 주지 않는다. 더 불러올 기록이 있으면 현재 불러온 건수임을 명시한다.
- 기록 상세의 테스트용 페이지네이션 데이터에는 사진 URL이 없어 사진 자리 표시가 나온다. 실제 사진 데이터가 포함된 기록의 로딩 결과는 별도 검증이 필요하다.
- 테스트 계정의 날씨와 알림 데이터가 비어 있어 해당 화면의 실제 값 및 알림 행 상태는 재현되지 않았다.

## 실행 확인

- iPhone 18 Pro 시뮬레이터에서 로그인 후 홈, 기록 내역, 기록 상세를 확인했다.
- 실제 화면 캡처는 `Documentation/PRScreenshots/153/`에 보관한다.
